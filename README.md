# 📚 STACK

## 🥞 Stack Using Array

An array-based stack implementation demonstrating the
LIFO (Last In, First Out) principle.

### Operations
- ➕ push()
- ➖ pop()
- 👀 peep()
- 🔄 change()

### Concepts
- 📌 LIFO
- ⚠️ Stack Overflow
- ⚠️ Stack Underflow
- 🔝 Top pointer
- 🧮 Array-based implementation

Example:

        TOP
         ↓
      ┌─────┐
      │  30 │
      ├─────┤
      │  20 │
      ├─────┤
      │  10 │
      └─────┘

    Last In → First Out

# 🔗 DOUBLY LINKED LIST

A Doubly Linked List implementation where every node maintains
both previous and next references.

### Operations
- ➕ Insert First
- ➕ Insert Last
- 🎯 Insert Before
- 🎯 Insert After
- ❌ Delete Particular Node
- 👀 Display / Traversal

Structure:

NULL ← [10] ⇄ [20] ⇄ [30] → NULL


# 🔄 CIRCULAR LINKED LIST

A Circular Linked List implementation where the last node
connects back to the head.

### Operations
- ➕ Insert First
- ➕ Insert Last
- 🎯 Insert Before
- 🎯 Insert After
- 📊 Ordered Insertion
- ❌ Delete First
- ❌ Delete Last
- ❌ Delete Particular Node
- 👀 Display / Traversal

Structure:

       ┌──────────────────────────┐
       │                          │
       ▼                          │
[10] → [20] → [30] → [40] ───────┘
  ↑
 HEAD

Check Java version:

Compile a Java program:

Run the program:

java FileName

Example:

javac Toh.java
java Toh
